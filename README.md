# 🧩 Maze Algorithm Visualizer (DFS vs BFS vs A*)

An interactive **Flutter-based maze game** built as a **Data Structures & Algorithms (DSA) college project** to visually compare popular pathfinding algorithms in a fun and educational way.

This app simulates a race between **Depth First Search (DFS)**, **Breadth First Search (BFS)**, and **A\*** as they navigate through a maze to reach a destination from a given source. Users can either generate a **random maze** or **design their own maze**, making it ideal for experimentation and learning.

After the simulation completes, the app presents a **detailed performance comparison**, showing which algorithm performed better and why.

---

## 🚀 Features

- 🧠 Real-time visualization of DFS, BFS, and A* algorithms  
- 🎮 Interactive and game-like UI with smooth animations  
- 🧩 Random maze generation and custom maze creation  
- 📊 Result comparison dashboard:
  - Path length  
  - Steps taken  
  - Nodes explored  
  - Execution time  
  - Algorithm efficiency  
- 🤖 AI-powered analysis using **Google Gemini**
- ❓ Ask AI questions like:
  - *Why did A* win this race?*
  - *Which algorithm was most efficient?*
  - *How does maze structure affect performance?*

---

## 🤖 AI Integration (Gemini)

The project integrates **Google Gemini AI** to provide intelligent, context-aware explanations based on actual algorithm execution data.  
Users can ask follow-up questions, and the AI explains:
- Why a particular algorithm won
- Trade-offs between DFS, BFS, and A*
- How maze characteristics impact performance

This makes complex DSA concepts easier to understand through real examples.
